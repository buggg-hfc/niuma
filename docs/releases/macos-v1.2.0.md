# 牛马脱敏器 macOS v1.2.0

在「设置 → 桌面外观 → 状态文案」可以把「上班中」改成「上钟中」，也可以分别调整其余五种状态。输入时会即时预览，支持逐项或整组恢复为当前职业的默认文案。

- 内置「通用」「上钟 / 下钟」「厨师」「建筑工人」「程序员」。每个职业分别记录自己的文案改动。
- 将六项预览存为新的自定义职业，之后可以切换使用或继续逐项调整。
- 保存后，完整悬浮窗和今日战报使用当前职业的文案。迷你模式在工作中优先显示下班倒计时。
- 升级时读取已有薪资和作息配置。早期版本没有状态文案配置时，使用「通用」预设。

## 下载与安装

| Mac 类型 | 下载文件 |
| --- | --- |
| Apple 芯片（M 系列） | `NiuMa-macOS-arm64-1.2.0.dmg` |
| Intel 芯片 | `NiuMa-macOS-x86_64-1.2.0.dmg` |
| 同时兼容两种芯片 | `NiuMa-macOS-universal-1.2.0.zip` |

适用于 macOS 13 或以上。升级前从菜单栏退出旧版，再打开 DMG，将「牛马脱敏器.app」拖入「应用程序」。安装包采用 ad-hoc 签名，未经过 Apple 公证，首次打开时系统可能要求手动确认。`SHA256SUMS.txt` 提供两个 DMG 和 Universal ZIP 的 SHA-256 校验值。

## 验证

Apple 芯片原生和 Intel 架构（Rosetta）各通过 73 项核心检查和 114 项 AppKit 检查。构建号为 `3`，源码标签为 `macos-v1.2.0`。
