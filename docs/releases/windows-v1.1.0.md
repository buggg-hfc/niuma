# 牛马脱敏器 Windows v1.1.0

在「设置 → 显示 · 状态文案」可以把「上班中」改成「上钟中」，也可以分别调整其余五种状态。编辑时可即时预览，支持逐项恢复和整组恢复为当前职业的默认文案。

- 内置「通用」「上钟 / 下钟」「厨师」「建筑工人」「程序员」。各职业分别保存自己的文案调整。
- 输入职业名称并点击「存为新职业」，即可把六项预览保存为新职业的默认文案。
- 保存后，完整悬浮窗与今日战报使用当前职业的文案。迷你模式在工作中显示下班倒计时。
- 旧版升级沿用现有薪资、作息和界面配置。新增的状态文案默认使用通用预设。

## 下载与运行

下载 `NiuMa-Windows.exe`，从托盘退出正在运行的旧版，然后双击运行新版。支持 Windows 10 和 Windows 11，使用 .NET Framework 4.8。`SHA256SUMS.txt` 提供可执行文件的校验值。
